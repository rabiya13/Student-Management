# Campusly Student Management

A responsive student management application built with React, Vite, and React Router. It includes seven pages: Dashboard, Students, Attendance, Courses, Fees & Payments, Timetable, and Reports.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build, run `npm run build`; to serve that build locally, run `npm run preview`.

Student records, attendance, and fee updates are saved in the browser's local storage. CSV export is available for student and fee records.
